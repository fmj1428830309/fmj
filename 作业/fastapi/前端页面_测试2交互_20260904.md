## 关键设计

### 测试2.py 的接口特征（与第5章不同）
- 端口 **8080**（不是 8000）
- 请求体用 **JSON body**（DepartmentCreate: {name, location}），不是查询参数
- 有完整 CRUD：POST / GET(列表) / GET(单个) / PUT / DELETE
- 用 SQLModel（db.exec(select(...)) 风格），模型是 Department
- **没有开 CORS** —— 这是前端最大的坑

### 跨域解决方案
测试2.py 没开 CORS，浏览器直接 file:// 或跨端口 fetch 8080 会被同源策略拦截。
方案：`serve_frontend.py` 用 http.server 提供页面（8081），并把前端发来的 `/api/*` 请求转发到 8080 后端，绕开 CORS。
- 前端 fetch 统一走 `/api` 前缀
- 脚本把 `/api` 前缀去掉后转发到 `http://127.0.0.1:8080`

### 前端功能
- 新增（POST JSON body）
- 列表（GET）
- 详情（GET /id）
- 编辑（PUT，表单切换编辑模式）
- 删除（DELETE，confirm 确认）

## 运行方式（两个终端）
```
终端 A：python 测试2.py          # 监听 8080
终端 B：python serve_frontend.py # 监听 8081
浏览器打开 http://127.0.0.1:8081
```
